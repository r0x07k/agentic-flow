# Memory

The **working memory**: the short, current gist of what the owner is working on, plus standing
context that does not live in code or in the registry. It is the fast briefing an agent reads to get
oriented — not a log and not a backlog.

> **Maintenance rule:** re-read this on every task completion and update it **only if the gist truly
> changed**. Prefer deleting stale lines to adding new ones; keep it short enough to read in a minute.
> The full inventory is [REGISTRY.md](REGISTRY.md); durable lessons go to
> [memory-longterm/](memory-longterm/README.md); the rules are in [AGENTS.md](AGENTS.md).
